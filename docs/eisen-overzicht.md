# Eisen aan het overzicht

Wat de redactie per opgezocht land te zien krijgt, en wat de tool daarbij nooit mag doen.

## Wat er per land in het overzicht staat

Je zoekt één land op. Voor elke overheid toont het overzicht:

| Gegeven | Toelichting |
| --- | --- |
| Basiskleur | De kleurcode die voor het hele land geldt |
| Deelgebieden | Afwijkende kleurcodes voor specifieke gebieden, met de naam van het gebied |
| Letterlijke typering | De eigen bewoording van die overheid, in de eigen taal |
| Vertaling | Diezelfde typering in het Nederlands |
| Citaat per deelgebied | Letterlijk fragment uit het advies, in de eigen taal |
| Vertaling van het citaat | Dat fragment in het Nederlands |
| Laatst gewijzigd | De datum waarop die overheid het advies aanpaste |
| Opgehaald op | Wanneer de tool het ophaalde |

Citaten blijven kort en uitgelicht, met een doorklik naar de volledige tekst bij de bron.
Anders loopt het overzicht vol en wordt het onleesbaar.

## Nooit samenvatten

De tool vat geen adviesteksten samen. Alleen letterlijk citeren, met vertaling ernaast.

Een eerdere versie van deze tool ging juist hierop mis: samenvattingen introduceren fouten
die niet opvallen, omdat het resultaat vloeiend en aannemelijk leest. Een citaat kan de
redactie verifiëren, een samenvatting niet.

Vertalen is geen samenvatten: de vertaling volgt de brontekst zin voor zin en staat naast
het origineel, nooit in de plaats daarvan.

## Drie uitkomsten, niet twee

Een leeg vakje is dubbelzinnig. Daarom onderscheidt de tool altijd:

1. **Een kleurcode** — opgehaald en vastgesteld.
2. **Geen bijzonderheden** — deze overheid heeft wel een advies, en dat is groen.
3. **Niet opgehaald** — de tool kon het advies niet bereiken of niet vaststellen.

Een eerdere versie meldde dat er niets was terwijl er wel degelijk een reisadvies bestond.
Dat is de gevaarlijkste fout die deze tool kan maken: het leest als "geen risico". Geval 3
is daarom altijd zichtbaar als een probleem, nooit als een uitkomst.

## Vormgeving

De huisstijl van Nederland Wereldwijd aanhouden, zodat het overzicht er meteen professioneel
uitziet en zonder uitleg doorgestuurd kan worden. Overzichtelijk, met duidelijke labels bij
de kleurcodes.
